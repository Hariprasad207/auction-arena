
# IPL Auction Arena

A multiplayer cricket auction simulation platform where users
create custom teams, join auction rooms and participate in
real-time player auctions.

## Technology Stack

### Frontend
- React
- JavaScript
- Vite
- Material UI

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA

### Database
- PostgreSQL
- Flyway

### Real-time
- Spring WebSocket
- STOMP

### Voice
- LiveKit / WebRTC

## Repository Structure

- frontend/ - React application
- backend/ - Spring Boot application
- database/ - Database documentation and scripts
- infrastructure/ - Docker and infrastructure configuration
- docs/ - Project documentation

## Development Status

Currently in the foundation and project setup phase.

## Development Rules

- Use feature branches for development.
- Submit pull requests to develop.
- Do not push directly to main.
- All changes must pass the agreed checks.
- Never commit secrets or environment files.
